    我的资料仓库

    链接会跟着「导出 JSON」一起走，换台电脑也还在； 本地上传的图片 / 文档只存在这台设备的浏览器里（IndexedDB），不上传、不联网，也不会进 JSON。

    ↑ 把图片 / PDF / 文档拖到这里，或点上面的「加文件」

    这是一个通用的学习计划板：先定周期，再定每天几点做什么，最后把要学的东西排成模块。

    出厂那四条线（专业课 / Python / AI / 英语）只是起步模板，不是给你规定的 —— 全都可以换掉。

    周期想多长就多长：几天、一个学期、一整年都行。休息日按星期设，节假日和调休可以单独加。

    每天的作息也是一个模版：学习日和休息日各一套，几点做什么、哪几段算主线，都能自己改。

    配套 40 张国标练习图纸：10 个图形 × 摹 / 临 / 默 / 检 各一张，DXF 格式，用任意 CAD 软件都能打开。

    整套计划都是模板，不是定死的。点「编辑计划」增删改模块、任务、时段； 点「计划周期」改起止日期和休息规则； 用「导出 JSON」备份或分享给别人，用「导入 JSON」在别的电脑上恢复。

    所有内容只存在你自己这台设备的浏览器里（localStorage），不上传、不联网、不需要注册。
